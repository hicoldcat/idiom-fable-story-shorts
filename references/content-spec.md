# 内容规范（Content Spec）

> 本文件是 `idiom-fable-story-shorts` Skill 的权威创作规范。
> 占位符在运行时替换：`{{THEME}}`（主题，默认自主挑选）、`{{NAME_PREFIX}}`（文件名前缀）、
> `{{DATETIME}}`（真实生成时间 `YYYYMMDDHHmmss`）。

---

## 一、创作目标与受众定位

### 1. 一句话定位

**一个成语，一个故事，55–70 个英文单词，30 秒讲完。**

孩子看完能说出"谁做了什么、结果怎样"，也就懂了这个成语的意思。
这是**讲故事**，不是讲知识，更不是讲科学。

### 2. 目标受众

- 核心受众：**5–10 岁儿童**，正在做英语启蒙，或刚开始听英文故事。
- 次级受众：陪看的家长、幼儿园与低年级英语老师。
- 语言要求：**英语必须是"能听懂的英语"**。一条里如果有 3 个以上孩子听不懂的词，这条就废了。
- 内容风格：像睡前故事，有画面、有对白、有节奏，不油、不假、不糊弄。

### 3. 一条好选题的标准

| 标准 | 具体表现 |
|---|---|
| 情节完整 | 起因、经过、结果三样都在，缺一样就不是故事 |
| 一句话能说清 | 家长看完能用一句话跟孩子复述 |
| 有画面 | 至少 3 个能画出来的动作（跑、躲、掉、砸、捡） |
| 有寓意 | 结尾能用一句简单的英文说出"这个故事在说什么" |
| 词够简单 | 5–10 岁孩子听完不卡壳 |

### 4. 什么不能做

| ❌ 不要 | 原因 |
|---|---|
| 讲完故事再补一段科学解释 | 那是科普片，30 秒装不下，也不是用户要的 |
| 把故事拆成多集 | 一条视频只讲一个故事，讲完为止 |
| 用故事讲"现代管理学/职场道理" | 儿童内容，寓意保持原味 |
| 为了塞知识改写情节 | 故事优先，情节不许改 |

---

## 二、选题数量与搭配

1. **恰好 10 条**，每条 = 一个成语或寓言 = 一条 30 秒视频。
2. **同一个故事不得出现两次**（校验脚本会查重）。
3. 默认配比：**成语 6–7 个 + 寓言 3–4 个**。
4. **题材要散**，10 条里尽量覆盖：
   - 动物为主角（狐假虎威、守株待兔、龟兔赛跑）
   - 人与自然 / 物件（刻舟求剑、揠苗助长、铁杵磨针）
   - 人物与选择（曹冲称象、司马光砸缸、望梅止渴）
   - 纯道理型寓言（北风和太阳、狼来了、蚂蚁和蚱蜢）
5. 难度分层：约 6 条给 5–7 岁（情节直白），4 条给 8–10 岁（有转折）。
6. **不选**含血腥、自伤、残酷细节的：杀鸡取卵、悬梁刺股、卧薪尝胆、割席断交。

## 三、中英文标题

### 1. 中文标题

- **自由发挥**，不要求出现"成语""寓言""故事"等字样 —— 加了反而像课件，不像短视频。
- 长度 **≤ 26 个汉字**。
- 风格：**自媒体感**，允许适度夸张，但必须守住"不骗人"这条线。
- 判断标准：家长刷到标题，能不能在 1 秒内猜出"这是哪个故事"。
  猜得出 → 合格；猜不出 → 标题只写了情绪，没写内容。

**四种可用的钩子句型**（10 条里至少混用 3 种）：

| 句型 | 模板 | 示例 |
|---|---|---|
| 悬念定格 | "他……，然后……" | 他刻了个记号，然后眼睁睁看着它漂走 |
| 反差打脸 | "明明……却……" | 他明明赢了，却自己把奖丢了 |
| 数字锚定 | "N 年 / N 句话" | 一根铁棒磨成针，到底要多少年 |
| 疑问钩子 | "为什么……？" / "真的……吗？" | 六岁孩子一句话，大人都没想到 |

**明确禁止**（属于低质标题党，校验脚本会给 WARN）：

- "震惊""吓傻""科学家都疯了""不转不是中国人""99% 的人都不知道"。
- 承诺视频里没有的内容。
- 编造"专家说""研究表明"来给标题加权重。

**允许的夸张**：语气夸张、对比夸张、时间夸张（"一辈子""五十年"），
**不允许的夸张**：事实夸张、结论夸张、因果夸张。

> 建议把故事名或故事里的关键物件写进标题（"树桩""铁棒""记号"）。
> 不写只给 WARN，不判错 —— 但会损失搜索流量。

### 2. 英文标题

- **自由发挥**，不要求出现 `Idiom` / `Fable` 等固定词。
- 长度 **≤ 14 个英文单词**。
- 用 Title Case（实词首字母大写）。
- 词汇必须是**小学阶段能读懂**的词。
- 英文标题不是中文标题的翻译，按英语观众的语感重写；可以更短、更直接。

示例：

- `He Marked the Boat. The River Kept Moving.`
- `The Harder It Blew, the Tighter He Held`
- `How Do You Weigh an Elephant? Ask a Six-Year-Old`

## 四、故事出处（必填字段）

格式一行写完：

```
**故事出处：** 成语「狐假虎威」｜《战国策·楚策一》
```

要求：

1. 标明类型：**成语** 还是 **寓言**。
2. 标明名称，用「」括起来 —— **校验脚本靠它查重**。
3. 出处能确认就写具体书名；**有争议或属"常见说法"的，写"常说出自《X》"**，不要硬编篇名。
4. 寓言统一写"《伊索寓言》"，不写版本、编者、年代、译者。
5. 一行写完，不写情节（情节放到下一栏）。

---

## 五、故事与寓意（必填字段）

两件事，一行写完，用 `｜` 分隔：

```
**故事与寓意：** 狐狸借着老虎的威风，把百兽都吓跑了｜比喻借着别人的力量来吓唬人。
```

要求：

1. **前半句是情节**：谁 + 做了什么 + 结果。≤ 40 个汉字，必须能独立复述。
2. **后半句是意思**：这个成语 / 寓言现在用来比喻什么。≤ 30 个汉字。
3. 情节以通行版本为准，不加戏。
4. 寓意照原样，不改写成鸡汤或职场道理。
5. 这句是给**家长和老师**看的，不是给孩子的旁白 —— 旁白里不要照搬。

---

## 六、核心单词（必填字段，3–5 个）

这是给英语启蒙用的"本集生词卡"。

```
**核心单词：** fox 狐狸｜tiger 老虎｜follow 跟着｜afraid 害怕｜power 力量
```

要求：

1. **3–5 个**，用 `｜` 分隔（校验脚本按 `｜` 计数）。
2. 必须是**这条旁白里真的出现过**的词。
3. 优先选：故事的关键名词（fox / tiger / boat）、关键动词（run / hide / drop）、
   关键形容词（afraid / clever / strong）。
4. 中文释义要短，2–4 个字，用孩子听得懂的说法。
5. 不要选 this / the / is 这类虚词。

---

## 七、英文旁白（核心交付物）

### 1. 词数与时长

- 目标时长 **约 30 秒**。
- 英文旁白 **55–70 词，硬性区间**。低于 55 撑不满 30 秒，高于 70 一定超时。
- 按 130–140 词/分钟的儿童故事语速估算，55–70 词 ≈ 24–32 秒（含停顿）。
- **不要为了凑字数重复内容、堆形容词**；不够就加一句对白，多了就砍修饰语。
- 校验脚本对越界判 **FAIL**（需要放宽时用 `--loose-words` 降级为 WARN）。

### 2. 四拍故事结构（30 秒骨架）

| 拍 | 时间 | 词数 | 任务 | 开场词 |
|---|---|---|---|---|
| 1 起 | 0–5s | 10–15 | 时间 + 谁 + 第一个动作 | `One day,` / `Long ago,` / `In a small village,` |
| 2 承 | 5–15s | 15–20 | 发生了什么，冲突出现 | `Then` / `So` / `But` |
| 3 转 | 15–24s | 15–20 | 转折，结果出来 | `But` / `Suddenly` / `Then` |
| 4 合 | 24–30s | 8–12 | 一句话点出寓意 | `So` / `And that is why...` |

**第 4 拍是寓意句，不是总结句。** 对比：

- ❌ 总结（只是重复情节）：`The fox walked in front and the tiger followed him.`
- ✅ 寓意（说出这个故事在讲什么）：`The tiger was strong. The fox was clever. Clever won that day.`

结构**要遵守，但不要机械套模板**：如果故事三句话讲不完，可以把"起"和"承"合并，
把省下的词全给"转"。

### 3. 语言要求（本 Skill 最容易翻车的地方）

**词汇**

- 优先使用高频常用词。判断标准：**一个学了两年英语的 8 岁孩子，能不能不查词典听懂**。
- 每条"超纲难词"**不超过 2 个**，且必须能从上下文猜出意思。
- 抽象词一律改写成大白话：

  | 不要用 | 改成 |
  |---|---|
  | approximately | about |
  | demonstrate | show |
  | utilize | use |
  | sufficient | enough |
  | acquire | get |
  | enormous | very big |
  | immediately | right away |
  | realize | find out |
  | recognize | know |
  | fortunate | lucky |
  | attempt | try |
  | observe | watch |

- 专有名词一条最多 1 个，能换成普通名词就换。
- 不用俚语、双关、需要西方文化背景才懂的梗。

**句式**

- 平均句长 **≤ 10 词**，单句 **≤ 15 词**（讲故事比讲知识更短）。
- 主动语态优先；一般过去时讲故事，现在时讲寓意。
- 多用对白：`"You can't eat me," said the fox.` —— 对白比叙述更好听、更好懂。
- 一个句子只装一个动作。不要 `He ran quickly across the field while the tiger watched him.`
- 可以用短句制造节奏：`The fox ran. The tiger ran. Everyone ran.`

**语气**

- 像一个有趣的哥哥 / 姐姐在讲睡前故事，不是老师在念课文。
- 可以直接对观众说话：`You know this one, right?`
- 允许一个小玩笑，但不要为了搞笑牺牲情节。

### 4. 单词数量标注

- 格式固定：`**单词数量（参考）：** 63 words`。
- **必填**，且必须等于脚本实测值（不一致判 FAIL）。
- 统计口径：去掉 Markdown 标记后按空白切分，含字母或数字的 token 计 1 词；
  数字、缩写、带连字符的词各计 1 词。

---

## 八、中文旁白

1. 完整传达英文旁白的信息和叙事顺序，一拍对一拍。
2. 中文要自然、有画面感，符合儿童口语习惯，**不要逐词直译**。
3. 不得添加英文旁白里没有的情节，也不得省略情节。
4. 中文里可以保留成语原文（"狐假虎威"）—— 这是内容资产，但只在寓意句出现一次。
5. 中文旁白要能直接拿去配音，念出来不拗口。
6. 汉字数 **≥ 30**（约等于英文 55 词的信息量）。

---

## 九、中文社交媒体贴文（抖音 / 小红书）

- 长度 **30–80 个汉字**。
- 必须贴合这条视频的具体情节，**不能只把标题重复一遍**。
- 可以用：一个提问 / 一句"我小时候也以为……" / 一个亲子互动邀请。
- 可以适量用 emoji（≤ 3 个），不要堆。
- 结尾优先抛一个**能让孩子回答的问题**，提高评论率。
- 不夸大，不用"震惊体"。

示例：

> 小时候背"狐假虎威"，只觉得狐狸狡猾。现在给娃讲才发现，真正好笑的是老虎——它一直以为大家怕的是狐狸。你娃第一次听，猜猜他会站哪边？

---

## 十、英文社交媒体贴文（X / YouTube Shorts）

- 长度 **20–50 个英文单词**。
- 不是中文贴文的翻译，按英语社交媒体的语气重写。
- 常用套路：`Most people remember X. Nobody remembers Y.` / 一个提问 / 一句金句。
- 可以带 1 个 emoji，不要多。
- 语言水平与旁白一致（简单、直接），不要突然变学术。
- 适合直接发布，用户不需要二次修改。

---

## 十一、话题标签

### 中文（5–8 个）

- 面向抖音 / 小红书，用常见、好搜的标签。
- 三层组合：**故事层**（#狐假虎威）+ **品类层**（#英语启蒙 / #儿童故事）+ **内容层**（#成语故事 / #睡前故事 / #动物故事）。
- **每条至少换掉 2–3 个标签**，不要 10 条一个样。
- 标签之间用空格分隔。

示例：`#狐假虎威 #成语故事 #英语启蒙 #儿童故事 #睡前故事 #动物故事`

### 英文（3–6 个）

- 面向 X / YouTube Shorts，用自然的英文标签。
- 兼顾系列标签（#ChineseIdiom / #AesopFable）、品类标签（#KidsStories / #LearnEnglish）、内容标签（#StoryTime）。
- 不加与内容无关的热门标签。

## 十二、儿童吸引力分析

一句话，说清**这条为什么能让孩子看下去**，必须落到具体机制：

- **熟悉感**：孩子听过这个成语，看到"它原来是个这样的故事"会有连接感。
- **反差**：结尾的反转出乎意料（老虎一直不知道真相）。
- **可模仿**：孩子能立刻演一遍（学狐狸走路、学老虎吼）。
- **代入**：孩子会想"如果我是狐狸/老虎，我会怎么做"。
- **亲子互动**：能拿这个问题去问爸爸妈妈。

禁止写："这个选题非常有趣""孩子一定会喜欢""内容生动活泼"这类空话。
必须能看出**具体是哪个机制在起作用**。

示例：

> 孩子多半听过"狐假虎威"这四个字，却不知道故事里老虎一直蒙在鼓里，这个信息差会让他忍不住想讲给同学听。

## 十三、准确性与内容安全

### 1. 故事侧

1. 一条视频只讲一个故事，不把两个成语的情节揉在一起。
2. 以通行版本为准，不加戏、不魔改；可以补镜头，不能补情节。
3. 寓意照原样，不改写成鸡汤或职场道理。
4. 出处不确定就写"常说出自"，不编篇名、不编年代。
5. 寓言版本众多，统一标"《伊索寓言》"，不编版本信息。
6. 不把成语包装成"古代科学预言"。

### 2. 英语侧

1. 语法必须正确，不能是"中文语序 + 英文单词"。
2. 时态统一：叙述用一般过去时，寓意用一般现在时。
3. 对白要用引号，说话人用 `said`，不要用生僻的 `exclaimed` / `retorted`。
4. 数字用阿拉伯数字或最简单的英文（`three` / `ten`）。
5. 一条里不要混用英式 / 美式拼写。

### 3. 儿童安全

1. 不出现血腥、恐怖、残酷细节。
2. 涉及动物时不描述伤害过程（"咬死"→"抓住了"）。
3. 寓意要正向，但一句话就够，别说教。

## 十四、最终内容结构

**输出文档只包含两个部分。**（质量检查清单属执行者自检，见第十七节，不写入交付文档。）

### 第一部分：10 个选题总览

```markdown
| 序号 | 中文标题 | English Title |
|---|---|---|
| 1 | … | … |
| … | … | … |
| 10 | … | … |
```

标题自由发挥，不要求出现固定词（详见第三节）。

### 第二部分：10 个选题的完整内容

每条严格按 `output-template.md` 的字段顺序展开：

1. `## 选题 N：中文标题`
2. `**中文标题：**`
3. `**English Title:**`
4. `**故事出处：**`
5. `**故事与寓意：**`
6. `**核心单词：**`
7. `**英文旁白（English Voiceover）：**`
8. `**单词数量（参考）：** XX words`
9. `**中文旁白（Chinese Voiceover）：**`
10. `**中文贴文（抖音 / 小红书）：**`
11. `**English Post (X / YouTube Shorts):**`
12. `**中文话题标签（Chinese Hashtags）：**`
13. `**英文话题标签（English Hashtags）：**`
14. `**儿童吸引力分析：**`

选题 2 至选题 10 结构完全相同。

## 十五、Markdown 格式与文件命名

### 1. 格式

- `.md` 文件，UTF-8 编码，中英文、emoji 正常显示。
- 清晰的标题层级（`#` 文档标题 / `##` 章节与选题）。
- 10 条及全部字段完整呈现，禁止省略式表述。
- **不要写"第三部分"**（校验脚本会给 WARN）。

### 2. 文件命名

`{NAME_PREFIX}-{YYYYMMDDHHmmss}.md`

- 未指定主题：`成语寓言-20261019101530.md`
- 指定主题（如"狐狸"）：`狐狸-20261019101530.md`
- 时间戳必须用 `date +%Y%m%d%H%M%S` 实取，**禁止占位符和虚构时间**。
- 文件名不含平台名、不含空格。

### 3. 交付

必须在文件系统实际创建 `.md` 文件，并通过 `present_files` 提供可点击的访问/下载链接。
禁止用聊天窗口的长文本代替文件交付。

## 十六、最终质量检查（执行者自检，不写入交付文档）

- [ ] 恰好 10 条，每条是一个独立故事，无重复。
- [ ] 成语 6–7 个 + 寓言 3–4 个，题材分散。
- [ ] 每条都有完整情节（起因 / 经过 / 结果）和一句寓意。
- [ ] 中文标题 ≤ 26 汉字，有钩子，能看出是哪个故事。
- [ ] 英文标题 ≤ 14 词，词汇简单，不是中文的直译。
- [ ] 故事出处标明类型、名称、出处。
- [ ] 故事与寓意写清"情节 + 比喻义"。
- [ ] 核心单词 3–5 个，都是旁白里出现过的。
